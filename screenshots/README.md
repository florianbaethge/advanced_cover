# Screenshots

These files are embedded in the root [`README.md`](../README.md) and the pages under [`docs/`](../docs).

| File | Content |
|------|---------|
| `advanced_cover_logo.png` | Project logo (README header) |
| `today.png` | Today tab — day timeline and today's plan |
| `covers.png` | Covers tab — cover list with capabilities and test buttons |
| `cover_edit.png` | Cover editor — capabilities, azimuth compass, low mode, window contact |
| `scenarios.png` | Scenarios tab — scenario list with sun-phase bars |
| `scenario_edit.png` | Scenario editor — When / Only if / Then / Covers |
| `log.png` | Log tab — action log |
| `card_all.png` | Dashboard card — all four sections |
| `card_next.png` | Dashboard card — next up |
| `card_timeline.png` | Dashboard card — day timeline with legend |
| `card_covers.png` | Dashboard card — covers with controls |
| `card_scenarios.png` | Dashboard card — scenarios with run buttons |
| `card_compact.png` | Dashboard card — compact tile |
| `card_editor.png` | Dashboard card — visual editor with live preview |

The panel shots are captured headless against a sandbox Home Assistant with a
demo config entry (four covers, a handful of scenarios). See
[`../scripts/make_screenshots.js`](../scripts/make_screenshots.js) to regenerate
them.

The card shots come from a demo dashboard (`ac-card`) on the same sandbox that
holds the card in every variation; see
[`../scripts/make_card_screenshots.js`](../scripts/make_card_screenshots.js).
